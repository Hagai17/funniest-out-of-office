## The entry

> I'm on holiday. My out-of-office reply has been on since 2019; this week, I finally joined it.

One line, 94 characters — an out-of-office auto-reply whose joke is that the
reply itself has seniority: it has been "on holiday" since 2019, and the human
only just caught up with it.
